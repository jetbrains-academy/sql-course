_This exercise is intended for those with prior experience in Kotlin. If you haven't worked with Kotlin before, feel free to skip it._ 

### Task
Fill in the placeholder in the editor pane so that by the end of the function, 
the **`mapRegionToSum`** map contains all regions except _Asia_ as keys, with each key  
mapped to the total number of airport movements in that region.

The input is a list of rows from the CSV file, with comma-separated values.
The format is the same as in the [airports.csv](course://Lesson1/airports.csv) file. The header row is automatically excluded from the input.
