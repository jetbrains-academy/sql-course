In this exercise, you will practice filtering grouped data using `HAVING` (for filtering entire groups) and selective aggregates
with `FILTER (WHERE …)` on the Astrofleet tables:

* `Planet(id, name, is_inhabited, climate, has_weapons, radius)`
* `Flight(id, num, planet_id, flight_date, spacecraft_id, people_count, cargo)`
* `Spacecraft(id, name, capacity)`

### Task
Read the task definitions in `task.sql` and replace each highlighted fragment so the queries return the
required result.

Click **Check** at any time to evaluate your work. If a solution fails, you will see a hint to help you fix it.
