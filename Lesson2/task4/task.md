## Exercise: writing simple expressions

In this exercise you have to edit a few expressions and make them returning the
expected results. Read the task definitions in `Query.sql` file, edit the code below the tasks
and click the button `Check`.

Please pay attention that there are placeholders in queries 3-5. You need 
to keep them in your solutions.

If some solution fails to pass a test, you will see the query with the expanded placeholders 
in the check output. The check will pass if all solutions pass all the tests.
