This exercise contains **two** queries. Each query includes a `?` placeholder that the
checker fills with different values — keep the `?` in both queries.

### Task
**Query 1 — `first_result`:** Modify the expression so that it returns true only when the
value equals the string `'the moon'`, ignoring case sensitivity.

**Query 2 — `second_result`:** Modify the expression so that it returns true only when the
value is the square of an integer from 2 to 10 inclusive. Hint: Use the `IN` operator.

Edit `task.sql` and click **Check**.
