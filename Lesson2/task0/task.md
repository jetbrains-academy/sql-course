# Using SQL as a calculator

We will start our journey with learning how we can calculate the values of arithmetic and 
other expressions using SQL. There is a wide variety of data types and operations 
in SQL, and they are mostly similar to data types and operations which you may have seen in other programming languages 
or use in the real life, for instance, in calculators. However, there are some surprises as well. 

Besides expressions, we will learn a few keywords which are used in SQL queries.
