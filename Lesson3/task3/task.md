In this exercise, you will write a few simple filters in the `WHERE` clauses of your queries.
All tasks operate on a single table named `Planet`, which has the following columns:

* `id` — Integer identifier of the planet
* `name` — Character string with the name of the planet
* `is_inhabited` — Boolean flag (`1`/`0`) indicating whether the planet is inhabited
* `climate` — Character string describing the planet's climate
  (one of `'cold'`, `'mild'`, `'warm'`, `'hot'`, or `'extremely hot'`)
* `has_weapons` — Boolean flag (`1`/`0`) indicating if there are dangerous weapons on the planet
* `radius` — Planet's radius

### Task
Read the task definitions in the `task.sql` file and replace the placeholder `true` expression in each
`WHERE` clause with an expression that solves the problem.

Click **Check** at any time to verify your work. If any solution fails, you will see a hint to help you fix it.
