## Exercise: writing simple filters in WHERE clause

In this exercise you have to write WHERE clauses with subqueries.
All the tasks will operate with a single table named `Planet` with the following columns:

* `id` is the integer identifier of the planet
* `name` is a character name of the planet
* `is_inhabited` is a boolean flag indicating if the planet is inhabited or not
* `climate` is a character string, which describes the planet climate.
  The list of possible values includes, but not limited to, `'cold', 'mild', 'warm', 'hot', 'extremely hot'`
* `has_weapons` is a boolean flag indicating if there are dangerous weapons on the planet

Please read the task definitions in `Query.sql` file, replace trivial expressions `true` in their `WHERE`
clauses with expressions that solve the tasks.

You can click "Check" at any moment. If some solution fails to pass a test, you will see
a hint which may help you to fix the problem.
