# Select data from a table

In this lesson we will learn how to select certain rows and columns from a single table.
The main focus will be on data filtering in `WHERE` clause.

The queries in this lesson will need a data source where the tables are stored. 
Exercise tasks will automatically create the data source, tables and add some data, and will
connect your SQL queries to the data source. If you want to run any of these queries elsewhere, 
you will need to use a database. For your convenience, we provide an SQLite database file
which you can use with SQLite console client.
