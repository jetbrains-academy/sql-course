## Exercise: rewriting queries to use join

In this exercise, you have to read a few queries which do not use explicit `JOIN` operators, and re-write them 
using `JOIN`.
Definitions of the tables and columns used in this exercise are given in `Schema.sql` file.

Please read the queries in the `Query.sql` file, and for each query type it re-written version in a placeholder below. 

You can click "Check" at any moment. If some solution fails to pass the test, you will see
a hint which may help you to fix the problem.
